  • Input and output axes, visible input splines and a recognizable output yoke.
  • Independent mounting features and external placeholder groups.
  • Stable component IDs so later geometry and fault states can be swapped without rebuilding the whole scene.

Accuracy boundary

This is not a dimensionally accurate 2022 OEM housing. Do not infer bolt patterns, shaft lengths, actuator locations or internal topology from this blockout. We will replace each provisional assembly as evidence becomes available.
